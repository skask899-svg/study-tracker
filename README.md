# Study Tracker

## Complete Documentation

### Features
- Track study time for different subjects.
- Set study goals and deadlines.
- Monitor progress with visual graphs.
- Generate reports on study habits over time.
- User-friendly interface for easy navigation.

### Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/skask899-svg/study-tracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd study-tracker
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

### Usage Guide
- After launching the application, create an account or log in.
- Start adding subjects and study goals.
- Use the timer feature to track your study sessions.
- View your progress on the dashboard and in generated reports.

### System Architecture
- **Client-Server Model**: The application is built on a client-server architecture with a frontend UI and a backend API.
- **Technologies Used**: React for frontend, Node.js with Express for backend, MongoDB for data storage.
- **Flow**:
  1. Frontend sends requests to the backend API.
  2. Backend processes requests and interacts with the database.
  3. Response is sent back to the frontend for display.
